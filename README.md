# Call History App v2 - update steps

Sirf "app_src" folder GitHub par dobara upload karo (same naam ki files overwrite ho jayengi).
".github" folder / build.yml ko chhedna nahi hai, wo pehle se sahi hai.

1. GitHub repository > Add file > Upload files.
2. Zip se "app_src" folder drag-drop karo > Commit changes.
3. Actions tab me "Build APK" apne aap chalega (5-10 min).
4. Naya APK download karo. PEHLE phone se purani Call History app UNINSTALL karo, phir naya install karo.
5. App kholo, 4 permissions do (naya: Contacts), phir call karke test karo.
